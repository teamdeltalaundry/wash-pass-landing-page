# WashClub — Image Asset Plan
**Role:** Senior Product Designer & Creative Director  
**Versi:** 1.0  
**Tanggal:** Juli 2026  
**Style Direction:** Startup Minimal · Apple-inspired · Flat Illustration · Blue & White

---

## Design Direction Brief

Sebelum masuk ke daftar aset, semua ilustrasi harus mengikuti DNA visual berikut:

| Atribut | Arahan |
|---|---|
| **Style** | Flat illustration, semi-3D isometric ringan |
| **Warna dominan** | Biru (#2D9CDB, #56CCF2) + Putih + abu sangat muda |
| **Aksen** | Gradient biru ke cyan, soft shadow biru |
| **Karakter** | Tidak ada wajah detail — gunakan abstract human shape atau silhouet minimalis |
| **Objek fokus** | Smartphone, kalender, paket laundry bersih, kurir urban, bubble sabun |
| **Dilarang** | Mesin cuci sebagai fokus utama, foto realistis, warna mencolok selain brand |
| **Vibe** | Clean, airy, modern, sedikit playful — seperti Notion, Linear, Stripe ilustrasi |
| **Format output** | SVG (ideal) atau PNG dengan transparent background |

## Rekomendasi AI Tools untuk Generate

| Tool | Keunggulan | Cocok untuk |
|---|---|---|
| **Adobe Firefly** | Output SVG-friendly, style konsisten | Semua ilustrasi flat |
| **Midjourney v6** | Kualitas tinggi, style control baik | Hero mockup, lifestyle |
| **DALL-E 3** | Mengikuti prompt detail dengan baik | Problem illustrations |
| **Recraft.ai** | SVG output langsung, flat illustration native | Semua aset SVG |
| **Figma + FigJam AI** | Editing langsung setelah generate | UI mockup, icons |
| **Rive** | Jika ingin animasi ringan di hero | hero-mockup-main |

**Rekomendasi utama: Recraft.ai** — satu-satunya tool yang bisa output SVG flat illustration secara langsung, cocok untuk semua 17 aset SVG di list ini.

---

## Catatan Implementasi

1. Semua file SVG harus dioptimasi dengan **SVGO** sebelum digunakan di produksi
2. Gunakan `loading="lazy"` untuk semua ilustrasi di bawah fold
3. Semua `<img>` harus punya `alt` attribute sesuai `copywriting/copywriting-master.md`
4. Jika SVG di-embed inline, tambahkan `aria-hidden="true"` untuk ilustrasi dekoratif
5. Format PNG hanya untuk OG image — semua yang lain gunakan SVG

---

*Image asset plan ini adalah panduan kreatif. Setiap aset dapat diganti atau disesuaikan tanpa mengubah struktur kode landing page.*
