# WashClub — Icon Assets

Folder ini berisi seluruh ikon yang digunakan pada landing page WashClub.

---

## Pendekatan Iconography

WashClub menggunakan **icon outline** dari library **Lucide Icons** (atau Heroicons sebagai alternatif).

- **Style:** Outline (bukan solid/filled)
- **Ukuran default:** 24×24px
- **Ukuran feature card:** 40×40px
- **Ukuran inline/kecil:** 16×16px
- **Stroke width:** 1.5px
- **Warna aktif:** `#2D9CDB`
- **Warna netral:** `#64748B`

Library referensi:
- Lucide: https://lucide.dev
- Heroicons: https://heroicons.com
- Phosphor: https://phosphoricons.com

## Cara Menggunakan di Kode

### Opsi A — Inline SVG (direkomendasikan)
Embed SVG langsung di HTML untuk kontrol warna via CSS:
```html
<svg class="icon icon-24" aria-hidden="true">
  <!-- paste SVG path dari Lucide -->
</svg>
```

### Opsi B — Lucide via CDN
```html
<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.min.js"></script>
<i data-lucide="truck" class="icon-feature"></i>
<script>lucide.createIcons();</script>
```

### CSS Ikon
```css
.icon-16 { width: 16px; height: 16px; stroke: currentColor; stroke-width: 1.5; }
.icon-24 { width: 24px; height: 24px; stroke: currentColor; stroke-width: 1.5; }
.icon-40 { width: 40px; height: 40px; stroke: currentColor; stroke-width: 1.5; }
```

## Cara Mengganti Placeholder

1. Export ikon dari Lucide/Heroicons dengan ukuran yang sesuai
2. Simpan dengan nama file yang sama persis
3. Hapus tag `[PLACEHOLDER]` dari file ini setelah diganti

---

*Seluruh placeholder ikon dapat diganti di kemudian hari tanpa mengubah struktur HTML.*
